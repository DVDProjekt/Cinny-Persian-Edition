# Cinny Persian Edition

A customized fork of [Cinny](https://github.com/cinnyapp/cinny) - Yet another Matrix client, enhanced with Persian/Farsi language support and additional visual themes.

## 🌍 What's New

This build introduces significant improvements focused on Persian language support and an expanded theme palette for better user experience.

### Key Features

#### 1. **Persian Typography**
- Replaced Arabic and Persian fonts with **Vazir** font family for improved readability and authenticity in Persian and Farsi text
- Enhanced font rendering for native Persian speakers
- Better kerning and ligature support for Persian characters

#### 2. **Automatic RTL/LTR Detection**
- Smart text direction detection that automatically switches to **RTL (Right-to-Left)** mode when the first character is Persian/Farsi
- Seamless bidirectional text support without manual configuration
- Improved user experience for mixed Persian and English content

#### 3. **Six New Themes**

Expanded the theme collection with six carefully designed themes:

| Theme | Description |
|-------|-------------|
| **Volt** | A vibrant, electric-inspired theme with bold accent colors |
| **BlueNeon** | Neon blue aesthetic with high contrast for night usage |
| **Ocean** | Calm, oceanic palette with blues and teals |
| **Nothing** | Minimalist, understated design with neutral tones |
| **Classic Sepia** | Warm, vintage-inspired sepia color scheme |
| **Gold** | Luxurious gold-accented theme with premium feel |

In addition to the existing themes:
- 💡 Light Theme
- 🩶 Silver Theme
- 🌙 Dark Theme
- 🧈 Butter Theme
